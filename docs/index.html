Designed for less rework

Project-wide Copilot instructions guide every coding task. Agents select specialized skills when the request calls for them. Command guardrails are reserved for supported hooks.

🎯

Invariant-First Discipline

Implement the requested behavior without mutating unrelated behavior. Task size changes investigation and test depth, not safety standards.

📚

Progressive Context Disclosure

Agents load concise SKILL.md guidance only when it matches the current task, and open detailed references only when needed.

🛡️

Clean as You Code

Repository analyzers, Roslyn warnings, Sonar rules, and .editorconfig guide new and materially changed code without expanding into unrelated legacy cleanup.

🔄

Composable Workflows

Skills compose naturally. A defect flows from bug-investigation → dotnet-implementation → unit-testing → targeted-validation → diff-review.

🔒

State-Tracked Safety

The TypeScript CLI tracks file digests in .dotnet-agent-skills.json. Repeated installs skip unchanged skills; force operations back up locally edited skills.

🌐

Works Across Agents

Canonical skills follow the portable SKILL.md format. The installer adapts their location for Codex, Copilot, Claude Code, and Cursor.

Agent compatibility

One canonical skill library, installed into the discovery location used by each supported agent. Copilot project installs also manage a section of repository instructions.

Built from experience

Less repetition.
Less token waste.
Less rework.

I created dotnet-production-agent-skills after repeatedly explaining the same production expectations to GitHub Copilot—then spending more tokens correcting and reworking the result. This project captures those lessons as focused, reusable guidance so coding agents can start with better context and produce safer .NET code the first time.
